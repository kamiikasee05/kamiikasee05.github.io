TUSTOCK

Gestión de stock y ventas para comercios · SaaS

En producción con un cliente pagando

Problema

Kioscos, librerías y almacenes llevan el stock y las ventas a mano o en planillas, con equipos viejos y, muchas veces, sin internet confiable. Necesitaban un sistema simple que no dependiera de la nube para funcionar.

Solución

Un sistema que corre 100% en la PC del local, se instala en 15 minutos y no requiere ser técnico para usarlo. Incluye una app Android para escanear códigos con la cámara del celular y un monitor cloud opcional para ver el local en remoto. Optimizado a propósito para hardware débil (2 núcleos / 4 GB de RAM).

Stack

Python FastAPI SQLAlchemy SQLite (WAL) React 18 TypeScript Vite Kotlin / Android ML Kit · CameraX Monitor cloud (Railway)

Resultado

Producto en producción, instalado en locales reales y con un cliente pagando. Lo llevé de punta a punta: código, instalación, capacitación y soporte. Funciona sin internet, se actualiza por pendrive y está pensado para que lo use cualquiera.

C

COMANDER

Sistema de comandas para gastronomía · producto

En etapa de lanzamiento

Problema

Los locales chicos toman pedidos por WhatsApp y por apps de delivery: los mensajes se pisan en la hora pico, el pedido se arma tres veces y los datos del cliente quedan en la app, no en el local.

Solución

Un sistema de comandas que corre en la computadora del local: el mostrador toma el pedido, la cocina lo recibe en un tablero con timer, el historial lo guarda y el encargado administra el menú y las promociones. Sin comisión por venta y sin depender de internet para operar.

Stack

Next.js 16 React 19 TypeScript Prisma SQLite Tailwind CSS 4

Resultado

Producto completo y funcional: mostrador, cocina (KDS) con timers, historial, admin de menú, promociones y login de encargado, con el menú real de una hamburguesería cargado para las demos. Está en etapa de lanzamiento: todavía no tiene clientes cerrados, y lo digo claro — lo que hay es el sistema andando y listo para probar.
